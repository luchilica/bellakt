# Корпоративный веб-портал ОАО «Беллакт» (Bellakt Employee Portal & Kiosk)

[![TypeScript](https://img.shields.io/badge/TypeScript-5.8-blue.svg?logo=typescript)](https://www.typescriptlang.org/)
[![React](https://img.shields.io/badge/React-19-61DAFB.svg?logo=react)](https://react.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4.0-38B2AC.svg?logo=tailwind-css)](https://tailwindcss.com/)
[![Vite](https://img.shields.io/badge/Vite-6.2-646CFF.svg?logo=vite)](https://vitejs.dev/)

Корпоративный веб-портал и Progressive Web Application (PWA) для сотрудников **ОАО «Беллакт»** — ведущего производителя детского питания и молочной продукции.

Система спроектирована как универсальная платформа самообслуживания сотрудников, одинаково оптимизированная как для **цеховых сенсорных инфокиосков и напольных терминалов** на проходных, так и для **личных мобильных устройств** (смартфонов и планшетов).

---

## 📌 Ключевой функционал

* 🍽️ **Столовая предприятия:**
  * Актуальное цикличное меню на всю рабочую неделю с фильтрацией по категориям (первые блюда, гарниры, мясо, выпечка, напитки).
  * Формирование обеденного талона с авторасчетом калорийности и итоговой стоимости.
  * Прямое списание стоимости обедов в счёт будущей заработной платы по табельному номеру.
  * Блокировка заказа на прошедшие даты и двухфакторное подтверждение с защитой от случайного клика в рабочих перчатках.
* 📄 **Заказ справок (КЭДО / Бухгалтерия):**
  * Моментальный заказ стандартных справок (о доходах за 3, 6, 12 месяцев, для визы, банка, субсидий и пособий).
  * Подача индивидуальных запросов в произвольной форме в кадровую службу.
  * Верификация оформления документа с предупреждением о регистрации заявки.
* 💰 **Расчетный листок:**
  * Прозрачный доступ к начислениям, окладу, премиальным выплатам и удержаниям по табельному номеру.
  * История расчетных листков по месяцам.
* 🩺 **Журнал здоровья (Санпропускник):**
  * Электронная предсменная фиксация самочувствия сотрудников пищевого производства (температура, состояние кожных покровов, допуск к смене).
* 📢 **Информационная лента и сервисы:**
  * Оперативные объявления руководства, графики дежурств, телефоны внутренней диспетчерской службы.
* 🖥️ **Режим терминала / Инфокиоска:**
  * Эргономичная сетка быстрого доступа 3x2 для больших сенсорных экранов.
  * Увеличенные интерактивные зоны (touch-targets ≥ 44px) для безошибочного ввода.
  * Устранение визуального шума: строгий запрет на отвлекающие красные бейджи-счётчики поверх навигационных карточек.

## 🎨 Дизайн-система и фирменный стиль

* **Цветовая палитра ОАО «Беллакт»:**
  * Основной корпоративный синий: `#002B7F`
  * Вторичный глубокий акцент: `#0B4DA2`
  * Пастельный фон карточек и бейджей: `#D6E6F9`
  * Нейтральный производственный фон: `#EDF2F7` (с поддержкой комфортной тёмной темы)
* **Адаптивность:** Полная поддержка разрешений от компактных смартфонов (360px) до Full HD терминалов и широкоформатных 4K-экранов инфокиосков.
* **UX/UI Регламент:** Минималистичная анимация загрузки логотипа в круге, отсутствие навязчивых уведомлений («toast-fatigue mitigation»).

## 🛠️ Стек технологий

* **Фронтенд:** React 19, TypeScript, Vite
* **Стилизация:** Tailwind CSS v4, Motion (Framer Motion)
* **Компоненты и доступность:** Radix UI / Base UI, Lucide React (пиктограммы)
* **Уведомления и формы:** Sonner, React Hook Form, Zod
* **Управление состоянием:** Zustand
* **PWA:** Поддержка работы в офлайн-кэше и установка на рабочий стол терминала

## 🚀 Быстрый старт

### Требования
* Node.js 18+
* npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Портал будет доступен по адресу: `http://localhost:3000`

### Проверка типов и линтинг
```bash
npm run lint
```

### Сборка для продакшена
```bash
npm run build
```
Статические файлы сборки сохраняются в директорию `dist/`.
